# Question bank (David's questions waiting to go into tests)

David drops questions here (pasted in chat; Claude saves them). The next test builds, including the overnight run, take them from **Waiting**, oldest first, as soon as each fits. See "Question bank" in `CLAUDE.md` for the rules.

Each entry has these fields:
- **Section**: reading, thinking or maths, plus the type if known (for example "maths: combinations").
- **Added**: the date.
- **Question**: the question text, its options and answer exactly as David gave them, and any notes. Pictures go in `content/bank/` and are linked from the entry.
- **Notes**: David's instructions, if any (for example "use as a stretch question").

When a question is used, move its entry to **Used** and add the test and question it became (for example "→ Test 47 Maths Q2"), plus anything that was changed.

Never paste in questions from the official sample papers or other copyrighted books. Only add David's own questions (or ones he confirms he may use).
